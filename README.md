# Shop Tracker

A desktop application for monitoring Shopee products in real time.

## Features

- Live product monitoring
- Price tracking
- Stock status tracking
- Clean desktop interface
- Activity logging
- Start / Stop monitoring

## Technology Stack

- Python
- Playwright
- CustomTkinter

## Current Version

Stable Build v1.0

## Roadmap

- Multi-product monitoring
- Independent browser tabs
- Discord notifications
- Automatic purchase workflow
- Standalone executable

## Development

This repository follows a stable-branch workflow.

- `main` always contains the latest stable release.
- New features are developed in separate feature branches before merging into `main`.
